# Linux support removed

This fork supports Windows 10/11 x64 only starting with the 1.8.3 development delivery.
Linux/Sober builds, desktop adapters, packaging, updates and CI jobs are removed.
Existing Linux data and previously published artifacts are not modified.

Historical release notes describe their original preview support; use the corresponding tagged upstream source for those versions.
See [Windows setup](../README.md) and [development](DEVELOPMENT.md).
